# About

Prompt was optimalized using Gemini 3.1 Pro in antigravity IDE. At first i created it in czech language, then i translated it to english using Claude Opus 4.6 Thinking in antigravity IDE.
I tested more than 10 different prompts to get the best possible result. I tried Gemini 3.1 pro extended, Claude Sonnet 5 Extra and Claude Opus 5 high. The worst result was by Gemini, game looked very simple and often had small bugs. Version by Claude Sonnet 5 Extra took so much time, version by Claude Opus 5 High was fastest and simply the best. Claude Opus 5 Extra took so much time and credits to generate.
